## 1. Rationale: Why the Architecture Is Not Merely a Sensor Dump

A system with 48,000 touch channels is not more embodied than one with 48.
The distinguishing property is that the signals arrive **late**, **adapt**,
are **predicted by the system itself**, and **matter** functionally:

| Mechanism | Location | Functional contribution |
|---|---|---|
| Conduction delay (18 / 60 / 250 ms by fibre class) | `afferents.py` | the brain acts on a stale body image, so a forward model is *necessary* |
| Receptor adaptation and habituation | `receptors.py`, `afferents.py` | steady contact is attenuated perceptually, analogous to the habituation to clothing |
| Reafference cancellation (corollary discharge) | `afferents.py` | self-generated touch is perceived differently from touch imposed externally |
| Learned body schema (`d proprio / d action`) | `predictive.py` | the notion that the body belongs to the agent, expressed as a measurable quantity |
| Interoception and homeostatic drives | `interoception.py`, `drives.py` | the agent possesses intrinsic *needs* |
| Affect modelled as gain-and-setpoint control | `affect.py` | emotions alter what the agent prefers, not merely its outward expression |
| Segmental postural prioritisation | `motor.py` | the body protects itself before movement is initiated |

Each of these mechanisms is measured in the outputs, so that the corresponding
claims are checkable rather than rhetorical.
