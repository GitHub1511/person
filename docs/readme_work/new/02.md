## 2. The body model

The model is generated programmatically from declarative tables in `skeleton.py` and
`skin.py`; `embodied_human/build_model.py` writes `out/models/human.xml`.

| | |
|---|---|
| Degrees of freedom (DoF) | **94 qpos / 88 qvel** (52 actuated joints + 6-DoF floating base + 5 free objects) |
| Mass | **71.68 kg**, with every segment assigned a human mass fraction |
| Actuators | 52, each subject to a human isokinetic **torque limit** (knee 200 N·m, ankle 110 N·m, hip 160 N·m, eyes 0.05 N·m) |
| Sensors | **2,118** MuJoCo sensors, yielding **2,186** `sensordata` values |
| Skin | **1,872 taxel sites** (tactile sensing elements) distributed over **40 body patches** |
| Geometry | 49 collision geoms, 1,885 sites, 38 bodies |

The body is oriented facing **−y**, with the vertical axis along **+z**, and every joint axis is derived from this convention in `skeleton.build_bones()`. The convention is consequential: in an earlier version, the knee, elbow, wrist and finger axes lay in the *frontal* plane rather than the sagittal plane, so that the legs exhibited no knee flexion at all and no controller could bring the body to a standing posture.

### Collision filtering (`build_model.py`)

Contact between two geoms is enabled when `(contype_A & conaffinity_B) or (contype_B & conaffinity_A)`, where the collision bits correspond to the categories *world*, *objects*, *left hand*, *right hand*, *trunk/head* and *limbs*:

```
         limb  hand_l  hand_r    body   world  object
  limb  False    True    True   False    True    True
hand_l   True   False    True    True    True    True
hand_r   True    True   False    True    True    True
  body  False    True    True   False    True    True
 world   True    True    True    True   False    True
object   True    True    True    True    True    True
```

* Limbs never collide with limbs or trunk → the body cannot disintegrate as a consequence of
  self-intersection (for example, a pelvis capsule lying inside a thigh capsule).
* Geoms of the *same hand* never collide → this eliminates the deep finger–finger
  interpenetration that would otherwise be registered as **370 kPa of phantom pain** on
  the fingers.
* The two hands, and either hand against the trunk/head, remain in collision →
  **self-touch is supported**, which is the essential purpose of a body schema.
