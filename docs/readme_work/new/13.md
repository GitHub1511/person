## 13. Extension Procedures

* **Additional skin region** — a `SkinPatch` is added to `skin.default_patches()`.
* **Additional emotion** — a profile (a set of weights over the appraisal
  dimensions) is added to `affect.EMOTION_PROFILES`, together with
  corresponding entries in `EMOTION_VALENCE`, `EMOTION_AROUSAL` and
  `EMOTION_TAU`.
* **Additional neuromodulator** — the neuromodulator is registered in
  `NEUROMODULATORS`, `NM_BASELINE` and `NM_TAU`, and a target expression is
  specified in `AffectSystem.update`.
* **Additional organ system** — state variables are appended to
  `interoception.INTERO_NAMES`, and the corresponding ordinary differential
  equations (ODEs) are specified in `update()`.
* **Additional drive** — the drive is registered in `drives.DRIVES`, with an
  associated setpoint and expression.
* **Additional motor program** — a `Policy` is added to
  `active_inference.default_policies()`.
* **Alternative personality** — a 5-vector `temperament` is supplied to
  `AffectSystem`.
