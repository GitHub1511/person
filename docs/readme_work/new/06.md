## 6. Homeostatic drives — the regulatory demands of the body

The model comprises 16 drives, each characterised by a level, an urgency
(amplified by allostatic load and stress), a setpoint, the current value, and
a **slope**, since a need that is deteriorating is regarded as more urgent
than one that is merely poor:

`hunger, thirst, sleepiness, thermal_cold, thermal_heat, pain, air_hunger,
nausea, bladder, fatigue, itch, social_need, safety, curiosity, comfort,
restlessness`

The drives constitute the **preferred observations** in latent space (§8);
consequently, they modify behaviour without any reward function having been
specified.
